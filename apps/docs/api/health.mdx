---
title: 'Health check'
description: 'Check that the API is running'
---

`GET /health` reports whether the API process is up. It does not check the database.

## Request

No authentication is required.

```bash
curl https://api.example.com/health
```

## Response

Returns status `200` with a JSON object containing `status: "ok"` and the process `uptime`.

Use this endpoint for uptime monitors and load-balancer health probes.
