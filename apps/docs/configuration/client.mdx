---
title: 'API client'
description: 'Call the API from TypeScript'
---

The `@repo/client` package wraps the HTTP API.

```ts
import { newClient } from "@repo/client";

// Keep the key on the server.
const client = newClient({ apiKey: process.env.API_KEY });

const status = await client.health();
console.log(status); // "OK"
```

Pass a `baseUrl` option to point the client at another host.
