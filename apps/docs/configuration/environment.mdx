---
title: 'Environment variables'
description: 'Every server variable the API reads'
---

The API validates its environment at startup with `@t3-oss/env-nextjs`. Missing optional values disable the related feature.

## Database

| Variable | Required | Format |
| --- | --- | --- |
| `DATABASE_URL` | Yes | A valid URL |

## Payments

| Variable | Required | Format |
| --- | --- | --- |
| `STRIPE_SECRET_KEY` | No | Starts with `sk_` |
| `STRIPE_WEBHOOK_SECRET` | No | Starts with `whsec_` |

## Email

| Variable | Required | Format |
| --- | --- | --- |
| `RESEND_FROM` | No | An email address |
| `RESEND_TOKEN` | No | Starts with `re_` |
